# 演示视频脚本

建议时长：2–3 分钟。  
录制方式：屏幕录制 + 麦克风讲解，分辨率 1080p，浏览器缩放保持 100%。

## 录制前准备

1. 运行 `start.bat`，打开 `http://localhost:8000/`。
2. 浏览器使用无痕窗口，确认没有插件遮挡页面。
3. 关闭无关窗口和通知。
4. 先点击一次“重置模型”或刷新页面，让页面处于初始状态。
5. 准备一个 GitHub Pages 在线链接，录制结尾时展示。

## 分镜脚本

### 00:00–00:15 开场

**画面：** 展示首页全貌，鼠标从标题移动到参数面板。

**旁白：**

> 大家好，这是我的《人工智能基础与应用》课程作品，Neural Playground 神经网络实验台。它完全运行在浏览器里，不需要后端和 API Key。

### 00:15–00:45 一键演示

**画面：** 点击“一键演示”，观察训练轮数、准确率和决策边界变化。

**旁白：**

> 为了让没有机器学习基础的同学也能使用，我准备了一键演示。点击后，系统会自动选择模型并开始训练。这里可以看到神经网络从初始状态逐步学习，决策边界随训练轮数发生变化。

### 00:45–01:10 查看结果

**画面：** 训练结束后，指向测试准确率、损失曲线、准确率曲线和混淆矩阵。

**旁白：**

> 训练完成后，测试准确率达到 100%。右边是损失曲线和准确率曲线，下面是测试集混淆矩阵。训练集和测试集是分开的，测试集不参与参数更新，所以这些指标可以反映模型的泛化能力。

### 01:10–01:40 对比线性模型和 MLP

**画面：** 切换到“同心圆”数据集，先选择“线性分类器”，训练几秒后暂停；再选择“小型 MLP”，重新训练。

**旁白：**

> 现在换到同心圆数据集。选择线性分类器时，决策边界只能是一条直线，所以无法把内圈和外圈正确分开。切换到小型 MLP 后，隐藏层让模型可以学习弯曲的边界，准确率明显提升。

### 01:40–02:05 调节复杂度和观察过拟合

**画面：** 切换到“螺旋”数据集，选择“深层 MLP”，把噪声调高，重新训练。展示训练准确率和测试准确率曲线。

**旁白：**

> 螺旋数据更难。这里可以选择深层 MLP，并调节噪声和训练轮数。随着模型变复杂，训练准确率可能继续上升，但如果测试准确率停滞，就说明模型可能开始过拟合。这个实验台的目的就是让这些概念变得可见。

### 02:05–02:25 悬停预测和导出

**画面：** 鼠标在决策边界附近移动，展示预测概率提示；点击“截图”和“JSON”按钮。

**旁白：**

> 鼠标悬停在画布上，可以查看任意位置的预测类别和置信度。实验结果可以导出为图片和 JSON，方便写实验报告和复现实验。

### 02:25–02:45 在线部署和收尾

**画面：** 打开 GitHub 仓库和 GitHub Pages 在线链接，展示手机端页面。

**旁白：**

> 作品已经部署到 GitHub Pages，桌面和手机都可以直接访问。整个项目没有后端依赖，所有计算都在浏览器中完成。以上就是我的课程作品，谢谢大家。

## 录制提示

- 不要全程朗读代码，重点展示“操作 → 结果 → 解释”。
- 鼠标移动要慢，关键指标停留 2 秒以上。
- 视频中至少出现一次 GitHub Pages 在线链接。
- 如果训练时间较长，可以剪掉中间等待，但不要伪造结果。
- 建议同时录制一段手机访问页面的画面，作为响应式证明。
