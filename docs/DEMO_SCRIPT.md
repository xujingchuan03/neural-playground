# 演示视频脚本

建议时长：2–3 分钟。  
录制方式：屏幕录制 + 麦克风讲解，分辨率 1080p，浏览器缩放保持 100%。

## 录制前准备

1. 运行 `start.bat`，打开 `http://localhost:8000/`。
2. 浏览器使用无痕窗口，确认没有插件遮挡页面。
3. 关闭无关窗口和通知。
4. 打开页面后先在控制台执行 `localStorage.clear()` 并刷新，或点击“关卡地图 → 重置进度”，让页面从第 1 关开始。
5. 准备一个 GitHub Pages 在线链接，录制结尾时展示。

## 分镜脚本

### 00:00–00:15 开场

**画面：** 展示首页标题、三个指标和“开始引导学习”按钮，点击进入关卡区。

**旁白：**

> 大家好，这是我的《人工智能基础与应用》课程作品，Neural Playground 神经网络实验台。它把神经网络拆成 10 个关卡，完全运行在浏览器里，不需要后端和 API Key。

### 00:15–00:45 第 1 关：训练是什么

**画面：** 引导卡显示第 1 关，点击卡片里的“开始训练”，观察决策边界从随机状态逐渐形成。

**旁白：**

> 第一关不需要任何基础。点击开始训练，模型先随机猜，再根据错误调整参数，边界会一步步成形。每关都会自动配好数据集和模型，并告诉你下一步点哪里。

### 00:45–01:10 第 2 关：一条直线分不开同心圆

**画面：** 点击“下一关”，系统自动切到同心圆 + 线性分类器；点击开始训练；停在 51.8% 的测试准确率。

**旁白：**

> 第二关故意让线性模型挑战同心圆。它只能画一条直线，所以测试准确率只有 51.8%，基本等于瞎猜。这说明问题不在训练时间，而在模型表达能力。

### 01:10–01:30 第 3 关：隐藏层让边界弯曲

**画面：** 进入第 3 关，自动换成小型 MLP，训练后准确率达到 100%，展示过关结论。

**旁白：**

> 第三关换成带隐藏层的小型 MLP，同样的数据立刻达到 100%。隐藏层先把平面做一次变换，再画直线，回到原空间边界就弯了。

### 01:30–01:55 第 8 关：数据错了，模型再强也没用

**画面：** 通过关卡地图跳到第 8 关，展示 30% 错误标签；训练后测试准确率约 78%；把错误标签调回 0，再训练，回到 100%。

**旁白：**

> 这一关在训练集里混入 30% 的错误标签。模型很努力，但测试准确率被压在 78% 左右。把错误标签清零，同样的模型立刻回到 100%。调参之前，先检查数据。

### 01:55–02:15 第 9 关：螺旋挑战

**画面：** 进入第 9 关，展示螺旋数据和深层 MLP 的弯曲边界，训练完成后准确率 100%。

**旁白：**

> 螺旋是最难的数据集。两条臂互相缠绕，边界必须跟着卷进去。完成这一关，说明已经理解了容量、轮数和调参之间的关系。

### 02:15–02:35 悬停预测、导出和关卡地图

**画面：** 鼠标在画布上移动，展示 P(A)、P(B)；点击“关卡地图”展示 10 关进度和 XP；点击截图和 JSON。

**旁白：**

> 悬停可以查看任意位置的预测概率。关卡地图记录学习进度和等级，实验结果可以导出为图片和 JSON，方便写报告。

### 02:35–02:50 在线部署和收尾

**画面：** 打开 GitHub 仓库和 GitHub Pages 在线链接，展示手机端页面。

**旁白：**

> 作品已经部署到 GitHub Pages，桌面和手机都可以直接访问。整个项目没有后端依赖，所有计算都在浏览器中完成。以上就是我的课程作品，谢谢大家。

## 录制提示

- 不要全程朗读代码，重点展示“操作 → 结果 → 解释”。
- 鼠标移动要慢，关键指标停留 2 秒以上。
- 视频中至少出现一次 GitHub Pages 在线链接。
- 如果训练时间较长，可以剪掉中间等待，但不要伪造结果。
- 建议同时录制一段手机访问页面的画面，作为响应式证明。
- 录制第 8 关时，务必让观众看清“错误标签 30% → 清零”的前后对比。
